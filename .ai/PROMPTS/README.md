# PROMPTS

Prompts prêts à l'emploi pour un assistant IA travaillant sur ce dépôt.
Contrairement aux checklists (qui sont bloquantes), les prompts sont des
**outils** : on les copie, on les adapte au besoin. Mais deux d'entre eux
sont **prescrits par le framework** :

- **`session_start.md`** — à copier en début de session pour installer le
  contexte et respecter l'ordre de lecture de `INDEX.md`.
- **`roles.md`** — obligatoire pour le débat multi-rôles §15.2 (niveau **C**,
  ou **S** en cas de désaccord).

Les autres (`nouvelle_fonctionnalite.md`, `correction_bug.md`,
`revue_de_code.md`) sont des gabarits utilitaires.

## Liste

- [`session_start.md`](session_start.md) — démarrage de session (prescrit)
- [`roles.md`](roles.md) — grille des 11 rôles techniques (prescrit)
- [`nouvelle_fonctionnalite.md`](nouvelle_fonctionnalite.md) — cadrage d'une
  feature
- [`correction_bug.md`](correction_bug.md) — diagnostic + fix ciblé
- [`revue_de_code.md`](revue_de_code.md) — relecture d'un diff
