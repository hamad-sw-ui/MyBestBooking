# PROMPTS

Prompts prêts à l'emploi pour un assistant IA travaillant sur ce dépôt.
Purement facultatifs — utilisez-les tels quels, adaptez-les, ou ignorez-les.

- `demarrage.md` — pour se remettre dans le projet en début de session.
- `nouvelle_fonctionnalite.md` — cadrage rapide d'une feature.
- `correction_bug.md` — diagnostic + fix d'un bug ciblé.
- `revue_de_code.md` — relire un diff avec des critères concrets.
