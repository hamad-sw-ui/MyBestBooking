# ✅ Aide-mémoire — avant d'ouvrir une PR

Non bloquant. À utiliser si ça vous rend service.

- [ ] `npm run build` réussit en local
- [ ] Les changements ont été testés à la main dans le navigateur (dev server)
- [ ] Description de PR : contexte, ce qui change, ce qui reste ouvert
- [ ] Captures d'écran si la PR touche l'UI
- [ ] Migrations Drizzle générées et commitées si le schéma a bougé
- [ ] Variables d'environnement documentées dans `DEV_ENVIRONMENT.md` si
      nouvelles
- [ ] Les fichiers `.ai/` concernés sont à jour dans la même PR
