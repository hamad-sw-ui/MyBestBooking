## Scénarios runtime

- non-admin sur `/api/admin/providers` → `403` ;
- admin enregistre Resend via UI API → metadata `source=database`, aucune clé dans la réponse ;
- ciphertext PostgreSQL contrôlé : valeur claire absente ;
- suppression admin → source `none`/fallback env ;
- Stripe configuré dans coffre → `/api/providers/stripe` retourne uniquement `pk_*`, jamais `sk_*` ni `whsec_*`.

## Limites explicites

Les clés de fournisseurs réelles, la rotation de master key et Playwright Chromium ne sont pas validés dans le sandbox. Voir `KNOWN_LIMITATIONS.md`.
