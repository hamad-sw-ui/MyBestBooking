# Analyse d'impact — T-181…T-185 (accélération non-régressive)

- **Date** : 2026-09-02

## Changements livrés

1. **T-182 `src/lib/read-cache.ts`** (+6 tests) : factory de cache TTL
   mémoire borné (pattern jumeau du cache settings T-179). Instance
   `publicCatalogCache` 60 s.
2. **T-182 recherche** : le catalogue **SANS dates** est caché 60 s par clé
   canonique (city/country/type/amenity/guests/minEUR/maxEUR/sort/page —
   bornes converties EUR, donc indépendantes de la devise affichée ; le
   payload caché est brut EUR, indépendant de la locale). **Avec dates** :
   disponibilité temps réel, **jamais cachée** (zéro surbooking).
3. **T-182 fiche** : vue **publique** (anonyme) cachée 60 s par slug ;
   utilisateur connecté (éventuellement hôte/admin → chambres inactives,
   brouillons) : chemin dynamique historique inchangé. La disponibilité par
   séjour (T-177) et les données viewer restent hors bloc caché.
4. **T-183 API catalogue** : `Cache-Control: public, s-maxage=30,
   stale-while-revalidate=60` **sans cookie session** ; `private, no-store`
   avec session (historique préservé).
5. **T-184** : recherche `count + page` parallélisées (clamp de page
   conservé); fiche `rooms + avis` parallélisés.
6. **T-185** : `scripts/perf-baseline.sh` + `npm run perf`.
7. **T-181** : deux idées **écartées après mesure** (images : egress
   Unsplash absent du sandbox ; optimizePackageImports : 0 octet gagné) —
   chacune documentée en commentaire de config.

## Risques et maîtrise

| Risque | Probabilité | Maîtrise |
|---|---|---|
| Contenu catalogue/fiche périmé ≤ 60 s (validation bien, avis approuvé, prix) | Certaine (par TTL) | **Borné et documenté** — même ordre que le cache maintenance T-179, accepté par les tests utilisateur (KNOWN_LIMITATIONS) |
| Fuite de données personnalisées via cache | Empêchée par construction | Payload caché = données publiques uniquement ; probes : bandeau wallet absent chez l'anonyme, présent chez le connecté sur la MÊME clé |
| Surbooking par dispo cachée | Nul | recherche AVEC dates + création réservation jamais cachées (validStay → wrap ignoré) |
| Régression pagination (clamp) | Couvert | `page=min(requested,totalPages)` conservé + relecture au bon offset si clamp |
| Multi-instance | Hors périmètre | cache process-local documenté (comme rate-limit store) |
